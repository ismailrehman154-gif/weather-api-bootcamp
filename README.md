# Weather Checker

Type in a city, get the temperature in Fahrenheit, what it feels like, the conditions, and the little weather icon.

![Weather Checker screenshot](screenshot.jpg)

The API speaks metric and nests everything three levels deep, so the hardest part was honestly just digging the right fields out of the response. The Fahrenheit conversion is one line. Finding the data took longer than the rest of the app combined.

OpenWeatherMap API, plain JavaScript. My code is on the `answer` branch.
